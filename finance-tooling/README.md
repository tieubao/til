# finance-tooling

Evaluations of financial tools: terminals, data providers, broker platforms, research software, trading frameworks.

Each tool is scored with the [5-question rubric](../ai-tooling/tool-evaluation-5-question-rubric.md) (same one used in `ai-tooling/`, applied here to finance). Filename convention: `<tool>-evaluation.md`.

Distinct from `finance/` (concepts like "how the bond market works") and `investing/` (personal investing philosophy). This folder is specifically tool reviews.
