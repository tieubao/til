## Context

A trio of related metaphors from programming language design, all extending the original "syntactic sugar" concept.

**Source:** [Wikipedia - Syntactic sugar](https://en.wikipedia.org/wiki/Syntactic_sugar)

## Definitions

**Syntactic sugar** is syntax within a programming language designed to make things easier to read or express. It makes the language "sweeter" for human use: things can be expressed more clearly, more concisely, or in an alternative style that some may prefer.

**Syntactic salt** is a feature designed to make it harder to write bad code. It adds friction intentionally, forcing the programmer to be explicit about potentially dangerous operations.

**Syntactic saccharin** (also called syntactic syrup) is gratuitous syntax that does not actually make programming any easier. It looks like sugar but provides no real nutritional value.

## Takeaway

Sugar helps readability, salt enforces discipline, saccharin is empty calories. When evaluating language features, ask which category they fall into.
